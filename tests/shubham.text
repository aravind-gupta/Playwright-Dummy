Standard Git Workflow (Team Environment)
1. Get Access + Clone the Project
Once you get access to a repo:
 
git clone <repo-url>
cd <project-folder>
 
This gives you a local copy of the project.
 
2. Always Start With Latest Code
Before doing anything:
 
git checkout main
git pull origin main
 
Ensures you're working on the latest codebase.
 
3. Create a Feature Branch (VERY IMPORTANT)
❌ Don’t work directly on main
✅ Always create a new branch
 
git checkout -b feature/login-api
 
Naming convention examples:
feature/user-auth
bugfix/login-error
hotfix/payment-crash
4. Make Changes in Code
Do your development work (add/edit files).
 
5. Stage and Commit Changes
git add .
git commit -m "Add login API with validation"
 
6. Keep Your Branch Updated (Important in Teams)
Before pushing, sync with main:
 
git checkout main
git pull origin main
git checkout feature/login-api
git merge main
👉 Resolves conflicts early.
 
7. Push Your Feature Branch
git push origin feature/login-api
